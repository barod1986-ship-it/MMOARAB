# Chrome Web Store graphic assets

Phase 8 intentionally contains **no invented branding artwork**. Final assets must be approved and generated from the real product identity before public submission.

Required/recommended asset contract used by this project:

- Store icon: 128×128 PNG.
- Screenshot: at least one current 1280×800 screenshot for every listing locale recorded for release; the V1 capture plan recommends up to five English screenshots covering the main workflow.
- Small promotional tile: 440×280 PNG/JPEG.
- Marquee promotional image: 1400×560 PNG/JPEG is optional for submission but may be added after brand review.
- Promotional video: a real **YouTube** URL showing the tested extension workflow is required by the current Store listing contract; never use a concept/mockup or outdated demo.

Promotional assets must not claim rankings, badges, unsupported providers/languages, or performance that the tested release does not prove.
