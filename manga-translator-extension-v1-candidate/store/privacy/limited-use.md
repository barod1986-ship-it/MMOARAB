# Limited Use statement

Manga Translator uses data obtained through Chrome extension permissions only to provide, maintain, secure, and troubleshoot its disclosed comic-image translation functionality. It does not sell user data, use it for personalized advertising, transfer it to data brokers, or use it for unrelated profiling. Human access to user data is not part of normal operation.

Any transfer to an approved translation provider must be necessary for the translation feature, match the provider disclosure shown in the product, and occur only after the consent required for that profile. Changes to data practices require an updated disclosure and consent before the new handling begins.

This statement is intended to satisfy the Chrome Web Store Limited Use disclosure requirement and must be published on the extension homepage or on a page one click away from it before public submission.
