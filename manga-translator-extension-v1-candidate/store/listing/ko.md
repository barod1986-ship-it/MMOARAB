# 스토어 등록 정보 — 한국어

**로케일:** `ko`  
**제목:** 만화 번역기 — 아랍어  
**요약:** 사용자가 직접 활성화한 만화·웹툰 이미지를 로컬 엔진으로 아랍어로 번역하고 효과음은 원본 그대로 보존합니다.

## 상세 설명

만화 번역기는 사용자가 명시적으로 활성화한 페이지의 만화 이미지 안 텍스트를 처리하고, 아랍어로 렌더링된 결과를 현재 읽기 화면에 표시합니다.

주요 기능:

- 현재 페이지에서 사용자가 활성화한 뒤에만 동작합니다.
- 백그라운드에서 웹을 수집하지 않고 화면에 보이거나 가까운 만화 이미지를 처리합니다.
- OCR, 레이아웃 분석, 글자 제거, 인페인팅, 아랍어 조판을 같은 컴퓨터의 Local Engine에서 수행합니다.
- 효과음은 번역·삭제·재그리기 없이 원본 픽셀을 보존합니다.
- 원본 이미지 복원 또는 이미 준비된 번역 결과 전환을 지원합니다.
- 로컬 결과 캐시는 설정에서 삭제할 수 있습니다.
- 일반 이미지 가져오기가 실패한 경우에만 사용자가 승인한 정확한 CDN 출처 권한을 요청합니다.

첫 페이지 데이터를 읽기 전에 Side Panel이 로컬 데이터 처리 내용을 명확하게 보여 주고 사용자의 명시적 동의를 받습니다. 이 동의는 외부 번역 제공자에게 이미지나 텍스트를 보내는 권한을 포함하지 않습니다.

번역을 사용하려면 같은 컴퓨터에 호환되는 Manga Translator Local Engine이 설치되어 있어야 합니다. 공개 다운로드와 지원 OS는 서명된 릴리스가 검증 게이트를 통과한 뒤에만 안내됩니다.

**최소 Chrome 버전:** 148.
