# ストア掲載情報 — 日本語

**ロケール:** `ja`  
**タイトル:** マンガ翻訳 — アラビア語  
**要約:** 明示的に有効化した漫画・マンファ画像をローカルエンジンでアラビア語へ翻訳し、効果音は原文のまま保持します。

## 詳細説明

マンガ翻訳は、ユーザーが明示的に有効化したページ上のコミック画像内テキストを処理し、アラビア語の翻訳画像を現在の閲覧体験に戻します。

主な機能:

- ユーザーが現在のページで有効化した後にのみ動作します。
- バックグラウンドでウェブ全体をクロールせず、表示中または近くのコミック画像を対象にします。
- OCR、レイアウト解析、文字消去、インペインティング、アラビア語組版は同じコンピューター上の Local Engine で処理します。
- 効果音は翻訳・消去・再描画せず、元のピクセルを保持します。
- 元画像への復元や、処理済み翻訳との切り替えができます。
- ローカルの結果キャッシュは設定から削除できます。
- 通常の画像取得に失敗した場合のみ、ユーザー承認後に特定 CDN オリジンへの権限を要求します。

初回のページ読み取り前に、Side Panel がローカルデータ処理を明示し、明確な同意操作を要求します。この同意は外部翻訳プロバイダーへの画像・テキスト送信を許可するものではありません。

翻訳には、同じコンピューターに互換性のある Manga Translator Local Engine が必要です。公開ダウンロードと対応 OS は、署名済みリリースが検証を通過した場合にのみ案内します。

**最小 Chrome バージョン:** 148。
