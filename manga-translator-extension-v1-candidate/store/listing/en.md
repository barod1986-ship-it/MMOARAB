# Store listing — English

**Locale:** `en`  
**Title:** Manga Translator  
**Summary:** Translate manga, manhwa, and manhua images into Arabic with a local companion engine while preserving sound effects.

## Detailed description

Manga Translator translates text inside comic images on the page you explicitly activate and renders the result back into the current reading experience.

Key features:

- Works only after you activate it on the current page.
- Detects comic images and processes visible/nearby content instead of crawling the web in the background.
- Uses a Local Engine on your computer for OCR, layout analysis, cleanup, inpainting, and Arabic typesetting.
- Preserves sound effects instead of translating, erasing, or redrawing them.
- Lets you restore the original image or toggle a ready translation without reprocessing.
- Uses a local result cache that you can clear from Settings.
- Requests exact image-CDN access only when normal acquisition fails and you approve that origin.
- Shows Local Engine/profile privacy behavior in Settings.

### Privacy before first use

Before Manga Translator reads comic images on a page for the first time, the Side Panel explains the local data handling and requires your explicit agreement. This local-processing consent does not authorize sending image or text data to an external translation provider.

If the selected approved profile sends extracted text to a named external translation provider, the Side Panel shows a separate provider-specific disclosure and requires an additional consent bound to that exact profile before translation starts.

The extension does not use page data for advertising, unrelated profiling, or external analytics. External telemetry is disabled by default.

### Companion requirement

Translation requires the compatible Manga Translator Local Engine installed on the same computer. Public download links and supported operating systems are listed only after their signed release artifacts pass the project's release gates.

**Minimum Chrome:** 148.
