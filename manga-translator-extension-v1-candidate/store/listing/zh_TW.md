# 商店資訊 — 繁體中文

**語言：** `zh_TW`  
**標題：** 漫畫翻譯器 — 阿拉伯語  
**摘要：** 將你主動啟用頁面中的漫畫、條漫圖片用本機引擎翻譯成阿拉伯語，並保留原始音效文字。

## 詳細說明

漫畫翻譯器只處理你明確啟用的目前頁面中的漫畫圖片文字，並把阿拉伯語結果重新顯示在目前閱讀體驗中。

主要功能：

- 僅在使用者主動啟用目前頁面後運作。
- 不在背景抓取網頁，只處理可見或接近視窗的漫畫圖片。
- OCR、版面分析、文字清除、修復與阿拉伯語排版由同一台電腦上的 Local Engine 完成。
- 音效文字保持原樣，不翻譯、不擦除、不重繪。
- 可以還原原圖，或在既有翻譯結果與原圖之間切換而不需重新處理。
- 本機結果快取可在設定中清除。
- 只有一般圖片取得失敗時，才會在你確認後要求特定 CDN 來源的選用權限。

首次讀取頁面漫畫圖片之前，側邊欄會清楚說明本機資料處理方式，並要求你主動同意。這項同意不授權把圖片或文字傳送給外部翻譯供應商。

翻譯需要在同一台電腦上安裝相容的 Manga Translator Local Engine。只有簽署的發行套件通過專案發布門檻後，才會公布下載連結與支援系統。

**最低 Chrome 版本：** 148。
