# Publisher / first-submission checklist

Public Store distribution is optional. Complete this checklist only if public distribution is chosen.

- [ ] Register the Chrome Web Store developer account and pay the one-time registration fee.
- [ ] Enable and verify Google Account 2-Step Verification for every account that can publish/update the item.
- [ ] Verify the monitored developer/support contact address.
- [ ] Use a publisher group only if shared ownership is actually required; grant the minimum members needed.
- [ ] Host the privacy policy at a stable public HTTPS URL.
- [ ] Host a homepage one click from the Limited Use statement/privacy policy.
- [ ] Host a support page or provide the monitored support URL/contact required by the listing.
- [ ] Finish Store Listing, Privacy, Distribution and Test instructions in the Dashboard.
- [ ] Upload the first item manually and preserve the assigned Store item/extension ID in release metadata.
- [ ] Confirm the actual Dashboard privacy checkboxes match `store/privacy/data-inventory.md`.
- [ ] Confirm remote-code declaration is **No** for the extension.
- [ ] Confirm every requested permission is justified and used by the submitted version.
- [ ] Confirm no broad permission or feature exists only for future use.
- [ ] Verify screenshots show the exact candidate UI and authorized content.
- [ ] Verify the required YouTube promotional video shows the real tested workflow and does not overclaim unsupported features.
- [ ] Verify the public Local Engine links point to signed/attested artifacts that passed Phase 7 gates.
- [ ] Verify Phase 5B production profile is frozen and the release privacy descriptor matches the Store disclosures.
- [ ] Run Chrome 148 and current Stable smoke tests from clean profiles/machines.
- [ ] Record the tested ZIP SHA-256 and prepare the Store candidate from that exact ZIP; do not rebuild between test and upload.
- [ ] Submit the first version manually. Use deferred/staged publication if a final compatibility check is still desired after review approval.
