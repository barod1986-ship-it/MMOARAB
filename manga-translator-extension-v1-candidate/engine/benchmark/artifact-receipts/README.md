# Artifact provenance receipts

Production receipts are generated by `engine/scripts/intake_model_artifact.py` from **explicitly supplied local bytes plus a reviewed review-record JSON**. This directory intentionally contains no forged receipts in source control before real artifacts are acquired.

A receipt binds the catalog revision, exact artifact bytes/tree digest, byte/file counts, provenance/retrieval URLs, upstream revision, review decisions, evidence links, and—when applicable—ONNX conversion provenance. The receipt itself is content-addressed by `receiptSha256`.
