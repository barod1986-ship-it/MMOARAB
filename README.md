# MMOARAB — تعريب Ragnarok Online / rAthena

مستودع خاص لمراجعة وتصحيح وتوحيد ومزامنة التعريب العربي بين خادم rAthena وملفات عميل Ragnarok Online.

## حالة العمل النشطة

بدأت **دورة مراجعة ثانية من الصفر**. لا نكمل من آخر ملف في المرحلة 292.

- دورة المراجعة: **2**
- آخر مرحلة مكتملة في الدورة الجديدة: **0**
- المرحلة التالية: **1**
- نطاق المرحلة 1: مدينتا **برونتيرا وإزلود**
- الملفات الأساسية:
  - `rathena-master/npc/cities/izlude.txt`
  - `rathena-master/npc/cities/prontera.txt`

لقطة المرحلة 292 القديمة محفوظة كسجل تاريخي وخط أساس للمحتوى فقط، وليست نقطة استمرار المراجعة.

## مبادئ المشروع

- تصحيح الترجمة لغويا وسياقيا، وليس مجرد توحيد الأسماء.
- تحديث `glossary/master_glossary.csv` في كل مرحلة، أو توثيق عدم الحاجة إلى تحديثه.
- الالتزام بالمصطلحات الثابتة في `glossary/fixed_terms.csv`.
- عدم ترجمة الاختصارات المحمية في `glossary/protected_tokens.txt`.
- مزامنة المصطلحات والمعرفات بين الخادم والعميل.
- فحص الخرائط والمدن وNPC والعناصر والوحوش والمهارات والمهام والملاحة والإنجازات وكل ملف مرتبط.
- الحفاظ على منطق السكربت والترميز ونهايات الأسطر.
- مرحلة واحدة وفرع واحد وPull Request واحد في كل مرة.

## أهم الملفات

- `AGENTS.md`: القواعد الإلزامية للذكاء الاصطناعي.
- `docs/STYLE_GUIDE.md`: دليل الأسلوب والوظائف والمصطلحات والاختصارات.
- `glossary/fixed_terms.csv`: المصطلحات الثابتة ذات الأولوية.
- `glossary/protected_tokens.txt`: الاختصارات الإنجليزية التي لا تترجم.
- `docs/SYNC_SCOPE.md`: مصفوفة المزامنة بين الأنظمة.
- `docs/AI_WORKFLOW.md`: دورة العمل لكل مرحلة.
- `glossary/master_glossary.csv`: القاموس الرئيسي المتوسع.
- `tracking/PROJECT_STATE.json`: حالة الدورة الحالية.
- `tools/validate_repository.py`: التحقق قبل الدمج.

## أمثلة ثابتة

- `Decrease AGI` ← `خفض AGI`
- `Increase AGI` ← `زيادة AGI`
- `Max HP` ← `أقصى HP`
- `ATK +10` ← `ATK +10`

تاريخ Git هو النسخة الاحتياطية؛ لا تنشئ مجلدات backup داخل المشروع.
