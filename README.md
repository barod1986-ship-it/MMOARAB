# MMOARAB — تعريب Ragnarok Online / rAthena

هذا المستودع الخاص هو مصدر الحقيقة لمشروع التعريب العربي. الحالة المعتمدة الحالية مبنية على لقطة المرحلة 292، دون مجلدات النسخ الاحتياطية وتقارير المراحل المتراكمة.

## الحالة الحالية

- المراحل المكتملة: **292**
- إجمالي التعديلات المسجلة: **65,775**
- ملفات NPC المراجعة بعمق: **293 من 555**
- ملفات المهام المكتملة: **88 من 88**
- الملف التالي: `rathena-master/npc/pre-re/guides/guides_lighthalzen.txt`

## المجلدات الأساسية

- `rathena-master/`: ملفات الخادم العربية والمراجع الإنجليزية.
- `System/`: ملفات العميل والنصوص المرتبطة.
- `data/`: الملاحة والكتب والملفات المرتبطة.
- `glossary/master_glossary.csv`: القاموس الرئيسي المعتمد.
- `docs/progress/`: حالة المشروع الحالية وقوائم المكتمل والمتبقي.
- `tracking/PROJECT_STATE.json`: نقطة توقف مختصرة قابلة للقراءة آليا.
- `tools/`: أدوات التحقق والمزامنة المحلية.

## طريقة العمل

1. لا تعدل `main` مباشرة.
2. أنشئ فرعا لمرحلة واحدة فقط، مثل `ai/stage-293-guides-lighthalzen`.
3. اقرأ `AGENTS.md` والقاموس وملف الحالة قبل التعديل.
4. راجع الفرق وشغّل `python tools/validate_repository.py`.
5. افتح Pull Request ثم ادمجه بعد نجاح التحقق.

لا تنشئ مجلد نسخة احتياطية قبل أي مرحلة؛ تاريخ Git هو النسخة الاحتياطية.
