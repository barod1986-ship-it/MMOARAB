# MMOARAB — تعريب Ragnarok Online / rAthena

مستودع خاص لمراجعة وتصحيح وتوحيد ومزامنة التعريب العربي بين خادم rAthena وعميل Ragnarok Online.

## الحالة النشطة

بدأت **دورة مراجعة ثانية من الصفر**.

- دورة المراجعة: **2**
- آخر مرحلة مكتملة: **1**
- المرحلة التالية: **2**
- نطاق المرحلة 2: **جيفن**
- الملف الأساسي:
  - `rathena-master/npc/cities/geffen.txt`

## ما تحتويه هذه الحزمة

- الأساس الكامل النظيف: `rathena-master/` و`System/` و`data/`.
- القاموس الرئيسي والمصطلحات الثابتة.
- سياسة المصادر الخارجية والمزامنة.
- GitHub Actions لتشغيل التحقق تلقائيًا.
- فاحص لمحتوى الترجمة والترميز والأسماء الداخلية والاختصارات المحمية.
- مستورد آمن ينسخ الحزمة إلى فرع مستقل دون استبدال `main` مباشرة.

## الاستيراد الأول إلى GitHub

من المجلد المفكوك شغّل:

```bat
tools\sync_clean_baseline_windows.bat
```

سينشئ البرنامج نسخة عمل مؤقتة، يستنسخ `main`، ينسخ ملفات الحزمة، يشغّل جميع أدوات التحقق، ثم يرفع فرعًا مستقلًا للمراجعة. لا يرفع ZIP ولا يكتب مباشرة إلى `main`.

## طريقة العمل بعد الاستيراد

1. أنشئ فرعًا لمرحلة واحدة.
2. اقرأ `AGENTS.md` والمراجع المذكورة فيه.
3. نفّذ التصحيح والمزامنة وتحديث القاموس.
4. شغّل أدوات التحقق محليًا.
5. افتح Pull Request وانتظر نجاح GitHub Actions.
6. ادمج بعد المراجعة ثم احذف فرع المرحلة.

## أهم الملفات

- `AGENTS.md`: قواعد العمل الإلزامية.
- `docs/STYLE_GUIDE.md`: دليل الأسلوب والمصطلحات.
- `docs/ONLINE_SOURCE_POLICY.md`: سياسة البحث والتوثيق.
- `docs/SYNC_SCOPE.md`: مصفوفة المزامنة.
- `docs/QA_AUTOMATION.md`: ما تفحصه الأدوات آليًا.
- `glossary/fixed_terms.csv`: المصطلحات الثابتة ذات الأولوية.
- `glossary/protected_tokens.txt`: الاختصارات الإنجليزية المحمية.
- `glossary/master_glossary.csv`: القاموس الرئيسي المتوسع.
- `tracking/PROJECT_STATE.json`: الحالة الآلية للدورة.
- `.github/workflows/qa.yml`: الحارس الآلي للـPR و`main`.

تاريخ Git هو النسخة الاحتياطية. ملفات ZIP وExcel والنسخ اليدوية تبقى خارج المستودع.
